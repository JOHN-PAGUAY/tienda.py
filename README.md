## 📌 Descripción del Proyecto
Este repositorio contiene un programa desarrollado en Python para la asignatura de **Fundamentos de Programación** de la Universidad Estatal Amazónica. El proyecto resuelve un problema sencillo de la vida real aplicando el uso de colecciones de datos (**listas**) para gestionar un inventario básico de productos en una tienda.

## ⚙️ Funcionalidades del Código (`semana15.py`)
El script implementa de forma secuencial los siguientes requerimientos de la tarea:
1. **Creación de la colección:** Inicializa una lista vacía (`productos = []`).
2. **Inserción de datos:** Utiliza el método `.append()` para registrar artículos de manera ordenada (Arroz, Azúcar, Aceite, Leche).
3. **Visualización:** Muestra de forma clara la información almacenada en pantalla mediante `print()`.
4. **Operación adicional (Eliminación):** Utiliza el método `.pop()` para remover un elemento específico de la lista según su posición.

## 🚀 Instrucciones de Ejecución
1. Asegúrate de tener instalado **Python** en tu equipo.
2. Descarga o clona este repositorio.
3. Abre una terminal en la carpeta del archivo o cárgalo en tu entorno de desarrollo (como VS Code, PyCharm o IDLE).
4. Ejecuta el programa con el siguiente comando:

   python semana15.py
